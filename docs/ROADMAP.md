# Roadmap do OrçaMaster

## Agora — Fundação

- Concluir auditoria técnica inicial.
- Confirmar origem de dados no Manus AI e Firebase.
- Criar fluxo de trabalho com Issue → Codex → PR → revisão → merge.
- Adicionar CI e padronização de código em PR separado.

## Próximo — Produto essencial

- Autenticação e empresas.
- Clientes.
- Produtos e serviços.
- Orçamentos com status, numeração, impostos e descontos.
- Conversão orçamento → fatura.
- Recibos e pagamentos.
- PDF profissional.

## Depois — Operação

- Dashboard financeiro.
- Relatórios por período.
- Lembretes de pagamento.
- Exportação CSV/JSON.
- Auditoria e logs.
- Backup e restauração.

## Escala — Produção estável

- Firebase sync/fallback.
- Monitoramento de erros.
- Regras fortes de banco.
- Deploy automatizado.
- Testes de regressão para fluxos financeiros.
